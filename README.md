# Makondo_Kitchen


This is a website that helps you have total control over your kitchen .
well at least its going to be when it is fully completed and all the features are done.
imagine you coming back from work and you are racking your brain about dinner and what you need to get before getting home. 
Not sure whether or not pepper is still remaining or not. 
No idea how to prepare o bake a dish.
well this website is here to solve all these kitchen related problems

it is built using html, css and javascript
